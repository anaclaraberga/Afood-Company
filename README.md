# Projeto Delivery - React
Este é um projeto de sistema de delivery desenvolvido utilizando React. A aplicação foi criada com o objetivo de simular um serviço de entrega de alimentos, onde o usuário pode escolher itens de um menu e fazer pedidos para entrega em sua localidade.

### Tecnologias Utilizadas

- React: Biblioteca principal para construção da interface.
- React Router: Para gerenciamento das rotas dentro da aplicação.
- Styled-components: Para estilização dos componentes de forma modular e reutilizável.
